# מסדר גלריה

אפליקציית אנדרואיד אישית שממיינת את תמונות הטלפון לתיקיות.

**שלב 1 (הגרסה הזו):** סורקת את הגלריה בטלפון עם ML Kit ומציגה אלבומים בתוך האפליקציה.
שום קובץ לא זז ולא נמחק.

## התקנה בטלפון
1. בטלפון, פתח: https://github.com/zionbag-ops/gallery-sorter/releases/latest
2. הורד את `gallery-sorter.apk` ופתח אותו.
3. אם אנדרואיד חוסם, אשר "התקנה ממקורות לא ידועים" לדפדפן.

גרסה חדשה מותקנת מעל הקודמת, ותוצאות הסריקה נשמרות.

## בנייה
כל push ל-`main` בונה APK ב-GitHub Actions ומפרסם אותו כ-release.
